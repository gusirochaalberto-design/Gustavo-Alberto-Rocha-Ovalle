# Actividad 3.3

| Capa | ¿Qué es? | ¿Para qué sirve? |
|---|---|---|
| **Capa 2: Enlace de datos** | Es la capa que conecta los dispositivos que están en la misma red local. Usa la dirección MAC. | Sirve para que los datos pasen de un dispositivo al siguiente dentro de la misma red y no se mezclen ni choquen. |
| **Capa 3: Red** | Es la capa que usa las direcciones IP para mover la información entre redes distintas. | Sirve para encontrar el camino (enrutar) y que los datos lleguen de un lugar a otro, aunque estén en redes diferentes. |
| **Capa 4: Transporte** | Es la capa que divide el mensaje en partes y usa puertos para saber a qué programa va. Usa TCP o UDP. | Sirve para que los datos lleguen completos y a la aplicación correcta. TCP confirma que llegaron y UDP no. |
